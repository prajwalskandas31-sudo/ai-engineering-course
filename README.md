## How to use this repo

1. Pick a module folder and open its `README.md`. It lists the videos, notes and files for that module.
2. `slides/` holds the lecture decks and `notes/` the study notes as PDFs. From Module 2 onwards, `code/` holds notebooks you can run.
3. Watch the matching video, then read the Notion notes and try the self-check questions.
